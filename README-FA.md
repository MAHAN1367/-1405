# قهرمان هدایت — نسخه دسکتاپ ویندوز

این پروژه پوسته Electron برای بازی سه‌بعدی «قهرمان هدایت» است. رابط و منطق اصلی بازی از فایل HTML ارائه‌شده نگه داشته شده و تنها ذخیره پیشرفت مرحله از `localStorage` به SQLite منتقل شده است.

## پیش‌نیاز ساخت

- Windows 10 یا 11 نسخه ۶۴ بیتی (برای ساخت محلی)
- Node.js نسخه 22
- دسترسی اینترنت هنگام نصب وابستگی‌ها و اولین ساخت

روی سیستم مقصدِ نصب‌شونده، Node.js یا مرورگر لازم نیست.

## ساخت نصب‌کننده در ویندوز

1. پوشه پروژه را استخراج کنید.
2. در همان پوشه PowerShell را باز کنید.
3. دستورهای زیر را اجرا کنید:

```powershell
npm install
npm run test:db
npm run dist
```

فایل نصب در این مسیر ساخته می‌شود:

```text
dist\GhahremanHedayat-Setup.exe
```

در صورت نیاز می‌توانید نام آن را به `Setup.exe` تغییر دهید. نام اصلی عمداً `GhahremanHedayat-Setup.exe` است.

## ساخت با GitHub Actions

پوشه پروژه را در یک مخزن GitHub قرار دهید و به شاخه `main` یا `master` ارسال کنید. از بخش Actions گردش‌کار **Build Windows installer** اجرا می‌شود. فایل نصب x64 به‌صورت Artifact با نام `GhahremanHedayat-Windows-x64-Installer` قابل دریافت خواهد بود.

گردش‌کار ابتدا lockfile را در محیط ویندوز ایجاد می‌کند، سپس `npm ci`، آزمون SQLite و `npm run dist` را اجرا می‌کند. به علت نبود دسترسی DNS به `registry.npmjs.org` در محیط فعلی ساخت این تحویل، امکان دریافت وابستگی‌ها و ساخت EXE در همین محیط فراهم نشد؛ بنابراین EXE آماده در این بسته وجود ندارد.

## نصب و حذف

- نصب‌کننده NSIS مرحله‌ای است و امکان انتخاب مسیر نصب را می‌دهد.
- میانبر دسکتاپ و منوی Start با نام فارسی «قهرمان هدایت» ساخته می‌شوند.
- نصب برای کاربر جاری انجام می‌شود و نباید به Administrator نیاز داشته باشد.
- حذف برنامه فایل‌های اطلاعات کاربر را پاک نمی‌کند.
- ممکن است Windows SmartScreen برای فایل بدون امضای دیجیتال هشدار نمایش دهد. در صورت اطمینان از منبع فایل، جزئیات ناشر/فایل را بررسی کنید؛ این پروژه امضای دیجیتال ندارد.

## محل داده‌ها و پشتیبان

اطلاعات خارج از پوشه نصب و در مسیر زیر ذخیره می‌شوند:

```text
%APPDATA%\GhahremanHedayat\
  Data\game.db
  Backups\
  Files\
  Logs\app.log
  Config\
```

این انتخاب عمدی است: پوشه نصب ممکن است فقط‌خواندنی باشد و حذف یا به‌روزرسانی برنامه نباید داده‌ها را پاک کند.

- پایگاه داده SQLite با `journal_mode=WAL` و `synchronous=FULL` تنظیم شده است.
- نسخه پشتیبان خودکار روزانه هنگام شروع برنامه و سپس هر شش ساعت ساخته می‌شود؛ ۳۰ نسخه روزانه اخیر نگهداری می‌شود.
- از منوی بازی می‌توانید پشتیبان `.db` بسازید یا بازیابی کنید.
- ورود و خروجی JSON برای انتقال داده‌های بازی نیز در منوی اصلی اضافه شده است.
- پیش از بازیابی، فایل بررسی می‌شود و از پایگاه داده فعلی نسخه `before-restore-...db` گرفته می‌شود.

**هشدار امنیتی:** پایگاه داده رمزنگاری نشده است. حفاظت آن به امنیت حساب ویندوز و در صورت فعال بودن، BitLocker وابسته است.

## نکته آفلاین

Three.js و فونت Vazirmatn به‌صورت وابستگی محلی npm تعریف شده‌اند و HTML دیگر به CDN یا Google Fonts ارجاع نمی‌دهد. برنامه در زمان اجرا درخواست شبکه‌ای نمی‌فرستد و درخواست‌های HTTP/HTTPS/WS/WSS/FTP در نشست Electron مسدود می‌شوند. برای ساخت اولیه، دریافت بسته‌های npm و باینری‌های Electron به اینترنت نیاز دارد.

## محدودیت‌های آزمون این تحویل

- سورس JavaScript از نظر نحوی بررسی شده است.
- بازرسی ایستا، نبود `localStorage`، `sessionStorage`، `indexedDB` و نشانی خارجی در HTML را بررسی کرده است.
- آزمون اجرایی `test-db.js` آماده است، اما در این محیط اجرا نشد؛ بسته‌های npm به دلیل خطای DNS قابل دریافت نبودند.
- ساخت Electron، ساخت NSIS و اجرای نصب‌کننده روی ویندوز واقعی در این محیط انجام نشده است.
- سازگاری ۳۲ بیتی ادعا نمی‌شود؛ هدف فقط Windows x64 است.

پس از نصب وابستگی‌ها، آزمون SQLite را با `npm run test:db` اجرا کنید.
